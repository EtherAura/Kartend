# LeakSanitizer suppressions for known/intentional leaks
#
# CacheManager normally drains and deletes its QThreadPool in the
# destructor (cooperative cancel via m_cancelIo + waitForDone(2s)).
# This suppression covers the rare fallback path where a long-running
# I/O task fails to notice the cancel within the timeout, in which
# case we abandon the pool rather than blocking exit. Remove this
# suppression once cache I/O is provably strictly cancellable.
leak:QThreadPool::QThreadPool

# Qt6 GStreamer multimedia backend leaks GstDeviceMonitor and its
# associated GstCaps/GArray/GPtrArray on first QMediaPlayer construction.
# These are global caches inside the platform plugin (loaded via
# QPlatformMediaIntegration::instance()) and freeing them is not in
# our control. Seen on Ubuntu 24.04 / Qt 6.4 / gstreamer 1.24.
leak:gst_device_monitor_new
leak:gst_device_monitor_add_filter
leak:libgstreamermediaplugin.so
leak:QPlatformMediaIntegration::instance
