// Kartend
Collection & Artwork Frontend for KDE

Kartend (German: Carding)
Carding is a mechanical process that aligns cotton, wool or other fibers in the manufacture of textiles. 
Kartend is a highly customizable frontend that will allow you to organize, manage, and launch your multimedia or applications. 

Dependencies:
```bash
sudo apt install clang cmake lld qt6-base-dev libqt6sql6-sqlite
```

The sculpture is already complete within the marble block, before I start my work. It is already there, I just have to chisel away the superfluous material.
