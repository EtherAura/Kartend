# Screenshot credits

Generated by `.vm/docs-shots.py` and `.vm/docs-video.py` — do not edit by hand.

The screenshots and videos in this directory show a demo library built
from open-licence material. CC BY and CC BY-SA require attribution, so
the artwork visible in them is credited here.

Screenshots: `library-grid.png`, `list-view.png`, `details-pane.png`, `search-filter.png`

Videos: `collections-tour.mp4`, `settings-tour.mp4`, `library-tour.mp4`, `theming-parallax.mp4`

Alterations, all of them reframing only — no work has been altered in
substance, recoloured or composited with anything not credited here:
game artwork is centre-cropped to 16:9 from the Wikimedia Commons
originals; the subcollection tiles in the collection walkthrough are
montages of the covers listed below; and the wallpaper in the theming
walkthrough is a 16:9 crop of the Elephants Dream poster.
